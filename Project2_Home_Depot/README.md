# Project 2: Public-company financial performance analysis

This portfolio project analyzes The Home Depot, Inc. for fiscal 2021–2025 and provides directional downside, base, and upside outlooks for fiscal 2026–2028.

## Deliverables

- `outputs/project2_home_depot/Home_Depot_Financial_Analysis.xlsx`: formula-driven Excel analysis workbook.
- `Project2_Home_Depot/data/financials_long.csv`: standardized statement data for Power BI or SQL.
- `Project2_Home_Depot/data/ratios_long.csv`: calculated ratio dataset.
- `Project2_Home_Depot/data/scenario_outlook.csv`: scenario output dataset.
- `Project2_Home_Depot/scripts/transform_financials.py`: reproducible SEC extraction and transformation.
- `Project2_Home_Depot/power_bi/`: Power Query, DAX measures, dashboard layout, and theme.
- `Project2_Home_Depot/Executive_Financial_Summary.md`: executive recommendation, drivers, assumptions, and limitations.
- `Project2_Home_Depot/Research_Methodology.md`: research design, definitions, validity, and reproducibility.

## Refresh

Run the Python transformation script, then rebuild the workbook or refresh Power BI. The model uses Home Depot's fiscal year labels and USD millions.

## Power BI limitation

This package includes all model inputs, queries, measures, layout instructions, and theme needed to build the report. A `.pbix` binary is not generated by the scripted artifact runtime and must be saved from Power BI Desktop after loading the included assets.

## Analytical extensions

The workbook includes estimated ROIC and NOPAT, accrual-based earnings-quality tests, operating-income attribution, acquisition-adjusted revenue analysis, product-category trends, a two-driver sensitivity matrix, explicit decision thresholds, and methodological limitations.
